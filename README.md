# Tutee Connect — France landing page

A faithful clone of the deployed reference site (`https://pageus.netlify.app/#/`),
localised for France. Same layout, same Tailwind classes, same scroll and hover
animations; only the copy, the photographs and the institution directory change.
Built 2026-09-01, the seventh country page after the UK, Canada, Ireland,
Germany, New Zealand and Australia.

Fidelity to the reference is measurable rather than asserted: the class multiset
of `index.html` differs from the UK page's by exactly **two** entries — the
currency glyph (`lucide-circle-pound-sterling` → `lucide-circle-euro`) and the
city-image key (`uk-city.jpg` → `france-city.jpg`) — and **all 1,062
animation-bearing class instances are identical**. `universities.html` differs by
nothing at all. Every localiser run additionally diffs the tag+class skeleton of
each fragment against its UK input and refuses to write if anything moved.

## How it was built

```bash
cd "../_tooling"

python3 build_dataset_fr.py           # ONISEP snapshots -> universities-data.js
python3 build_dataset_fr.py --refresh # ...re-downloading all three sources first
python3 localise_fr.py                # fragments-france/ + main.js + services-data.js
python3 assemble.py france            # index.html
python3 build_unipage.py france       # universities.html
python3 verify_site.py france         # every check
python3 check_twins.py france         # review the unlocalised text nodes
```

The content mapping — visa names, work rights, fees, language tests and the
family position — is `../_tooling/FRANCE_SPEC.md`. Read that before changing any
copy.

## The three things a reader should know

### 1. The directory is a filtered register, not a permission list

Australia's CRICOS and New Zealand's Code of Practice list *are* the legal right
to enrol an international student, so listing them is not a judgement call.
**France has no such instrument.** A VLS-TS « étudiant » is granted on a
pre-inscription at a recognised higher education institution, so the directory is
the ONISEP national register — published by the education ministries' own
operator — filtered by the register's own type column to institutions a foreign
applicant can actually apply to.

What that filter drops is as important as what it keeps: lycées (the entity is a
secondary school), apprenticeship centres (they need a French employment
contract), UFR/IUT/INSPE (components of universities already listed, so they
would duplicate), and the French-language quota-limited health and social-work
institutes. The four **écoles normales supérieures** and **Institut polytechnique
de Paris** are added back by name, because the register files them under headings
the filter drops and three of them are QS-ranked. Full reasoning is in the header
of `assets/js/universities-data.js` and in FRANCE_SPEC.md §4.

### 2. Nothing in the dataset is invented

The UK page's `offerRate` is a placeholder percentage and is still flagged as a
launch risk in `../UK/README.md`. This page does not repeat that:

- **`sector`** is the register's own `statut` column — Public / Private /
  Private (contracted) / Private (independent). Real, published, **100%
  coverage**, and the field that actually decides an applicant's fee regime.
- **`programs`** is derived from the register's own course catalogue (28,580
  courses joined by UAI), using its closed twenty-domain classification — real
  data for **966 of the 1,156** institutions. For the other 190 the catalogue has
  no entry and the descriptor falls back to the institution's **registered
  type**, which is still a real field, simply coarser. It is never a
  per-institution guess. A course *count* is deliberately **not** used the way
  Ireland uses one, because this catalogue is a guidance catalogue rather than an
  exhaustive inventory and would understate a university with a thousand
  programmes.
- **`rank`** is the **QS World University Rankings 2027**, which covers 38 French
  institutions — so all twelve carousel cards carry a genuine ranking and no
  badge had to be rewritten, unlike New Zealand.

### 3. The page is honest about family, and that is a downgrade

France is the **least generous of the seven destinations** on dependants: there
is no student dependant visa at all. A partner can only come on a
« visiteur » long-stay visa, which carries no right to work. The real family
pathway runs through the Passeport Talent *after* graduation, at which point the
partner gets a « talent — famille » card and works with no authorisation.

The UK copy promised a dependant visa. Reproducing it here would have been a
straightforward untruth, so the `#relocate` section and the family FAQ both lead
with what does not work before describing what does.

## Two notes for whoever builds country eight

**The ranking edition moved.** The other six pages were built against QS **2026**
and their directory notes still say so. QS **2027** was published on 18 June 2026
and is what this page uses. Those six are now one edition stale — a `uni_note`
refresh, not a rebuild.

**Markdown does not render in the fragments.** The chat replies in `main.js` are
markdown-rendered, so `**bold**` works there and the UK file uses it. HTML text
nodes are not. An early draft of the FAQ answers here carried four `**...**`
spans and shipped visible asterisks; it was caught by diffing the built page
against the UK one, which has none. Adding real `<strong>` is not the fix either
— that changes the DOM skeleton and the localiser refuses to write.
